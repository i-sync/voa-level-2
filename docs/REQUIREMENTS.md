# VOA Level 2 Player — 产品需求（MVP）

版本：0.4
日期：2026-08-31  
状态：可用，Lesson 1–30 已补齐并使用 1080p 视频

## 1. 背景

VOA Learning English 的 **Let's Learn English - Level 2** 课程内容质量高，单课同时提供视频、音频和完整 Conversation 文本，但原页面不满足长期重复学习的几个核心需求：

- 不能方便地选择 `0.70 / 0.80 / 0.90` 等细粒度速度；
- 缺少整课循环；
- 缺少 15、30、45、60 分钟后自动停止；
- 使用 VLC 时课程名称、顺序和文本难以统一管理；
- 使用 VLC 加 iPhone 系统计时器需要跨多个 App 重复操作；
- 官方 RSS 在实际客户端中内容不完整，不能作为课程目录来源；
- 手机向下阅读字幕时，原播放器离开视口，暂停、继续和后退操作不够方便。

本项目不是重新制作一套课程，而是给 VOA 已有课程增加一个更适合手机反复听的轻量播放器。

## 2. 产品目标

第一版应让用户只打开一个网页，就能完成以下学习流程：

1. 选择一课；
2. 看视频或听音频；
3. 将速度调到 0.70–1.50；
4. 打开整课循环；
5. 设置停止时间；
6. 向下阅读完整对话，并继续在屏幕底部控制同一个音频；
7. 下次回来继续上一次课程和进度。

## 3. 非目标

MVP 明确不做：

- 用户账号、登录、云同步和数据库；
- React、Vue、Next.js 等前端框架；
- 后台管理系统或运行时抓取服务；
- 单句时间轴、字幕自动高亮和点击跳转；
- A-B 循环、跟读录音、评分、生词本；
- 下载或镜像所有视频、音频到自有服务器；
- 原生 iOS / Android App；
- 广告、付费和公开商业化。

这些内容只有在 MVP 被真实使用并验证后才重新评估。

## 4. 用户与设备

主要用户：项目创建者本人。  
主要设备：iPhone Safari。  
次要设备：桌面 Chrome / Edge。  
主要场景：睡前息屏听、通勤泛听、看文本精听。

## 5. MVP 功能需求

### FR-01 课程目录

- 页面应列出已导入的课程，格式为 `Lesson N: Title`。
- 可以从下拉框选择课程。
- 支持上一课和下一课。
- URL 应包含 `?lesson=N`，便于收藏和返回。
- 课程目录包含连续的 Lesson 1–30，不包含 Review 页面。

### FR-02 视频播放

- 使用浏览器原生 `<video controls playsinline>`。
- Lesson 1–30 均使用 VOA 提供的 1080p MP4；数据中记录 `videoQuality: 1080`。
- 能拖动进度、暂停和继续。
- 播放视频时自动暂停音频。
- 记录每课视频播放位置。

### FR-03 音频播放

- 使用浏览器原生 `<audio controls>`。
- 优先使用 VOA 128 kbps MP3，并记录 `audioFormat: "mp3"` 与 `audioBitrate: 128`。
- 若课程页没有独立 MP3，则使用该课最小清晰度 MP4 的音轨，并记录 `audioFormat: "mp4"` 与 `audioFallbackVideoQuality`。
- 当前 Lesson 8 使用 240p MP4 音轨作为音频来源；它的视频仍为 1080p。
- 支持 iPhone 锁屏后继续播放；是否稳定以真机测试结果为准。
- 播放音频时自动暂停视频。
- 记录每课音频播放位置。
- 在手机宽度下，用户启动过本课音频并向下滚动到原播放器完全离开视口后，将同一个 `<audio>` 固定在屏幕底部。
- 浮动状态显示 `Lesson N · Title`、原生音频控件、后退 10 秒和前进 10 秒。
- 在浮动播放器中暂停后仍保持显示，方便继续播放；滚回原位置、切换视频、切换课程或离开手机宽度时自动收起。
- 页面始终只有一个音频元素，不复制媒体实例，不重新加载或同步第二个播放器。
- 浮动播放器避让 iPhone 底部安全区域，并为字幕末尾和 Toast 留出空间。

### FR-04 播放速度

- 常用快捷速度：0.70、0.80、0.90、1.00。
- 支持以 0.05 为步长调整。
- 有效范围：0.50–1.50。
- 视频和音频使用同一个速度。
- 速度保存在 `localStorage`，切课和重新打开页面后保持。
- 尽可能保持原音调，避免慢速时声音明显变低。

### FR-05 整课循环

- 提供开启/关闭开关。
- 开启后，当前视频或音频结束时自动从头播放。
- 循环偏好保存在 `localStorage`。

### FR-06 睡眠定时

- 快捷选项：15、30、45、60 分钟。
- 支持输入 1–240 分钟的自定义时长。
- 显示剩余倒计时。
- 到点后暂停视频和音频。
- 支持取消定时。
- 定时依据绝对时间戳，而不是只递减页面计数。
- 在 `setTimeout`、每秒检查、媒体 `timeupdate`、页面重新可见和重新聚焦时重复校验。
- iOS 锁屏可能暂停网页 JavaScript；真机必须测试到点误差。页面恢复后必须立即校正并停止。

### FR-07 Conversation 文本

- 在媒体下方展示完整英文对话。
- 角色名称与台词有清晰视觉区分。
- 支持放大/缩小文本字号，便于手机阅读。
- 第一版是静态全文，不要求时间轴同步。

### FR-08 学习状态记忆

使用 `localStorage` 保存：

- 上次打开的课程；
- 每课音频播放位置；
- 每课视频播放位置；
- 默认播放速度；
- 循环状态；
- 尚未结束的睡眠定时绝对时间；
- 已学完课程标记；
- 对话文本字号；
- 上次选择的音频/视频模式。

若上次进度距离结尾不足 8 秒，下次从头开始。

### FR-09 锁屏媒体信息

- 在浏览器支持 Media Session API 时，显示课程标题、VOA Learning English 和课程系列名。
- 尽可能支持系统界面的播放、暂停、前后跳转、上一课和下一课。
- 这是渐进增强；不支持时不能影响基础播放。

### FR-10 来源与异常处理

- 每课保留 VOA 原页面链接。
- 页面固定标明课程来源及“非官方学习工具”。
- 音频或视频载入失败时显示友好提示，并保留打开原课程的路径。

## 6. 数据需求

运行时只读取本仓库的静态文件 `data/lessons.json`。MP3 课程示例：

```json
{
  "id": 1,
  "title": "Budget Cuts",
  "sourceUrl": "https://learningenglish.voanews.com/...",
  "videoUrl": "https://..._1080p.mp4?cb=...",
  "videoQuality": 1080,
  "audioUrl": "https://..._hq.mp3",
  "audioFormat": "mp3",
  "audioBitrate": 128,
  "transcriptStatus": "complete",
  "transcript": [
    { "speaker": "Anna", "text": "..." },
    { "speaker": null, "text": "..." }
  ]
}
```

没有独立 MP3 的课程使用：

```json
{
  "audioUrl": "https://..._240p.mp4?cb=...",
  "audioFormat": "mp4",
  "audioFallbackVideoQuality": 240
}
```

数据更新通过开发时脚本完成：

```text
VOA 课程索引与单课页面
          ↓
scripts/import_voa.py
          ↓
data/lessons.generated.json
          ↓
人工检查差异并运行测试
          ↓
data/lessons.json
```

网站不能在用户访问时实时抓取 VOA。

## 7. 技术约束

- 原生 HTML、CSS、JavaScript；
- 无构建步骤；
- 无运行时第三方依赖；
- 静态托管，可直接部署到 GitHub Pages；
- Python 导入器只用于开发时更新数据；
- 远程媒体仍由 VOA 提供，第一版不承担媒体存储和带宽；
- 移动优先，最低宽度 320px；
- 页面必须通过 HTTPS 部署，以获得更稳定的移动媒体能力。

## 9. 已知风险

### R-01 iOS 后台定时器

锁屏后媒体可由系统继续播放，但网页 JavaScript 可能被挂起。因此 MVP 的定时停止是多路径、尽力而为的实现。若真机证明无法满足需求，下一阶段只针对该问题评估：

1. 是否有更可靠的 Web 媒体事件方案；
2. 是否使用轻量原生壳；
3. 是否由服务器生成固定时长播放资源。

在测试失败前，不提前引入这些复杂度。

### R-02 VOA 媒体地址变化

媒体链接来自 VOA CDN，未来可能失效。导入脚本应可重新生成数据，页面同时保留原课程链接作为回退。

### R-03 页面结构变化

导入器依赖 VOA 页面结构。脚本失败时应明确报错，不应静默生成空数据；生成结果必须人工检查。

### R-04 MP4 音轨兼容性

Lesson 8 当前没有独立 MP3，音频播放器使用 240p MP4。桌面与 iPhone Safari 都应单独验证其播放、倍速、循环和锁屏行为。若兼容性不稳定，再考虑只为这一课托管抽取后的音频，而不是扩大整个系统架构。

## 10. 后续候选功能

仅在 MVP 日常使用稳定后考虑：

- 搜索和筛选课程；
- A-B 循环；
- 为台词生成时间轴，实现当前句高亮和单句循环；
- “听一句—暂停—复述—重播”模式；
- 离线音频；
- 主屏幕图标和更完整的 PWA 能力。
